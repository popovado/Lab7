# Лабораторная работа №7: TCP-Сокеты в Java

## Тема
Клиент-серверное взаимодействие по протоколу TCP с использованием сокетов в Java. Реализация эхо-сервера с обработкой строк по варианту.

---

## 🎯 Цель работы
- Освоить принципы работы с TCP-сокетами в Java.
- Реализовать клиент-серверное взаимодействие по модели «запрос-ответ».
- Научиться корректно управлять сетевыми ресурсами и обрабатывать исключения.

---

## 📋 Задание (вариант 32)
**Название:** Эхо с подсветкой цифр  
**Описание:** Обозначить цифры в строке, заключая их в квадратные скобки.  
**Пример:**  
`"a1b2"` → `"a[1]b[2]"`

---

## 🛠️ Технологии
- Java 11+
- Maven (если используется)
- TCP-сокеты (`Socket`, `ServerSocket`)
- Потоки ввода-вывода (`BufferedReader`, `PrintWriter`)
- Многопоточность (`ExecutorService`)

---

## 📂 Структура проекта
src/
├── main/
│ └── java/
│ ├── client/

│ ├── server/
│ │ ├── Server.java # Серверное приложение
│ │ ├── ClientHandler.java # Обработчик подключений
│ │ └── StringProcessor.java # Логика обработки строки
│ └── NetworkScanner.java # (*) Сканер доступных серверов 


---

## 🔧 Особенности реализации
- Сервер использует `ServerSocket.accept()` для ожидания подключений.
- Каждое соединение обрабатывается в отдельном потоке через `ExecutorService`.
- Обработка строки производится в классе `StringProcessor`.
- Корректное освобождение ресурсов через `try-with-resources`.
- Дополнительно реализован сканер `NetworkScanner` для поиска серверов в сети.

---

## 🧪 Тестирование
- Запуск сервера: `java server.Server`
- Запуск клиента: `java client.Client`
- Тест: ввод `a1b2` → получение `a[1]b[2]`
- Проверка через `telnet localhost 9999`

---

## ✅ Результат
Сервер корректно обрабатывает строки, выделяя цифры в квадратные скобки. Клиент отправляет запросы и получает ответы. Реализована многопоточная обработка, корректное управление ресурсами и обработка исключений.
